# Gabon pathobiome

Abbate, Nkoghé, Akué, Becquart, Leroy & Roche. "Exposure risk, not within-host interactions, structures a human pathogen community".

Repository: https://github.com/rocheben/gabon-pathobiome

## Contents
- `data/` – survey data (`gabondata_master_utf8.csv`, UTF-8 copy of the Mac Roman encoded original) and complete-case files
- `code/` – analysis scripts (01–12), `asa_functions.R`, one script per figure, `save_figure.R` (figure export helper) and `run_all.R`
- `resultats/` – result tables written by the analysis scripts (the values reported in the manuscript)
- `figures/` – figures written by the figure scripts, named after their number in the manuscript and in SI Appendix, each as a vector SVG and a 600 dpi PNG

## Reproducing the analyses
All paths are relative to this folder. In R (4.3.3 or later), run (the working directory is set to this folder automatically):

    source("code/run_all.R")

Required packages: lme4, blme, splines, boot, bnlearn (4.9), Hmsc, igraph, ggplot2, pbapply (progress bars); missing ones are
installed from CRAN by `code/setup.R`, which `run_all.R` calls first. Total run time is about 20 min to one hour
(`11_hmsc_jsdm.R` is the longest step). Random seeds are fixed in each script. Hmsc model objects (`resultats/hmsc_model_*.rds`)
and the prepared data (`resultats/prepped.rds`) are regenerated by the scripts and are not included.

Re-running the scripts with the same package versions reproduces the tables exactly. With other versions of the
model-fitting packages, results can differ slightly: optimiser rounding in the GLMMs (`02`, `08`), and Monte Carlo
variation in the Hmsc MCMC (`11`, `12`), where pairs whose posterior support lies close to the 0.95/0.05 threshold
can switch between supported and not supported. The tables in `resultats/` are those reported in the manuscript.
